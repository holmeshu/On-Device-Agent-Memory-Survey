# Contributing

Thank you for helping maintain this resource.

## Suggest a Paper or Benchmark

Open a GitHub Issue or propose a change through a pull request. Include:

- The full title, authors, year, and DOI or public paper URL.
- The relevant memory form, lifecycle operation, personalization function, device context, or evaluation dimension.
- A short explanation of the connection to on-device agent memory.
- An official code or benchmark link, if available.

## Update Deployment Evidence

Distinguish the device used for sensing or interaction from the hardware executing formation, retrieval, updating, and memory-conditioned reasoning. Provide a Methods section, deployment description, or official artifact supporting a proposed evidence label.

## Correct an Existing Entry

Identify the entry and provide the authoritative source supporting the correction. Keep source identifiers and reference metadata consistent with the paper index and BibTeX file.

## Content Scope

Link to publisher pages, DOI landing pages, preprints, and official project resources. Use links to papers rather than uploading copies of third-party full texts.
