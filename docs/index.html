◎ OVERVIEW · SECTIONS 1–2

SECTION 1 · INTRODUCTION

Memory, under everyday constraints.

Personal devices bring together continuous multimodal experience, bounded resources, and a user's long-term history. Useful agent memory must connect all three.

This survey connects memory forms and lifecycle management to personalization, then examines deployment evidence, evaluation, and the challenges of sustained use on personal devices.

SECTION 2 · FOUNDATIONS

What is on-device agent memory?

Read Section 2 ↗

Memory as an evolving state

Agent memory keeps information from past observations, actions, and feedback available to the current decision process.

History→Memory→Action
Episodic
Specific experiences and the context in which they occurred.
Semantic
Facts and relationships usable beyond a single episode.
Procedural
Reusable skills and ways of carrying out an activity.

Short-term and long-term memory describe retention; working memory describes the active use of information in an ongoing task.

Local memory, within explicit limits

On-device agent memory is retained and processed on a personal device under resource budgets and data-use rules.

Peak runtime memory covers the agent as a whole: memory processing and model inference draw on the same available capacity.

Persistent storage preserves memory across interactions. Its budget limits the total storage footprint of the chosen system configuration.

Response time runs from receipt of a request to return of its result. Memory access and processing share this response budget with inference.

Energy includes both interactive processing and background maintenance over the period of operation. Moving maintenance off the response path still consumes energy.

Data-use rules

Specify what may be retained, for how long, and for which tasks. Later access, disclosure, correction, and deletion remain subject to user authorization.

01 MEMORY FORMS · SECTION 3

Five ways to retain experience.

A form defines the units in which memory is stored and reused. These forms can coexist: a personal fact, a reusable skill, and a repeated context need not share the same representation.

EXPLICIT & INSPECTABLE

Textual memory

Selected experience is retained as natural language or structured text, making personal information available for direct inspection and revision.

02 LIFECYCLE MANAGEMENT · SECTION 4

Memory is a process.

A memory store needs more than a write path. Its contents must enter tasks at the right time, incorporate new evidence, and leave when they are no longer useful or permitted.

01

Formation

Decide what enters memory, in which units, and with what provenance.

Admission · Units · Provenance
02

Retrieval

Decide when to access memory, where to look, and how much evidence to return.

Triggering · Routing · Reduction
03

Evolution

Consolidate jointly valid evidence and update facts or procedures as conditions change.

Consolidation · Updating
04

Forgetting

Control continued residence and influence through selection, deletion, and unlearning.

Selective · Directed · Unlearning
03 PERSONALIZATION · SECTION 5

Remembering, for a particular person.

Personal histories help an agent interpret preferences, resolve references, and anticipate needs. Privacy safeguards constrain how that history is retained and used throughout the system.

PREFERENCES

What do I tend to choose?

Learn from explicit feedback and repeated behavior, while allowing preferences to change with context and time.

PERSONAL REFERENCES

What does this mean to me?

Link a request to the people, places, possessions, and experiences in a particular user's world.

PROACTIVE ASSISTANCE

Is this a useful moment to help?

Use recurring intent and present conditions to judge whether an intervention is timely and welcome.

Privacy across the pipeline

Local storage reduces exposure. Retention rules, access control, and filtering before disclosure are still needed when personal memory is used.

↗ OPEN CHALLENGES · SECTION 8

What remains open?

Sustained use on personal devices raises questions that extend beyond a single successful retrieval.

01

Resource-aware lifecycle management

Coordinate retrieval and background maintenance as memory, workloads, and available resources change.

02

Reliable memory evolution

Preserve provenance and meaning through successive summaries, updates, and derived records.

03

Continual personalization

Carry uncertainty forward and revise personal preferences as circumstances and feedback evolve.

04

Privacy protection in memory use

Carry restrictions through derivation and reassess permitted use as tasks and purposes change.

05

Verifiable forgetting

Check removal from stored records and learned influence while preserving unrelated capabilities.

06

Long-term evaluation on real devices

Connect controlled histories to sustained interaction, accumulated costs, and the user's management burden.
