# Foundations

[Back to the resource page](../README.md) · [All papers](all-papers.md) · [BibTeX](../references.bib)

Agent memory retains information from past observations and interactions for later decisions. On-device memory operates under explicit resource budgets and rules governing retention, access, and disclosure. Cognitive roles and retention timescales do not prescribe separate storage modules.
