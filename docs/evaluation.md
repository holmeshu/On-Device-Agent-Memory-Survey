# Evaluation

[Back to the resource page](../README.md) · [All papers](all-papers.md) · [BibTeX](../references.bib)

Capability and device-cost measurements cover complementary aspects of agent memory. Device-context benchmarks identify collection or interaction settings. Their target device does not establish an end-to-end local memory pipeline.
