# Memory Forms

[Back to the resource page](../README.md) · [All papers](all-papers.md) · [BibTeX](../references.bib)

The survey organizes memory into five forms according to the basic units retained. Subcategories follow the manuscript. Papers cited as examples or related mechanisms are included without implying that every system was executed on-device.
